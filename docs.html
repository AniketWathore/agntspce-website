AgntSpce

An open source desktop workspace for running and monitoring AI coding agents inside PTY-backed terminals.

AgntSpce combines workspace management, agent launches, live terminal output, git-aware status tracking, and token-compression metrics in one app. It runs entirely locally — no cloud dependency, no account required.

Requirements
  • macOS (Apple Silicon or Intel) — Windows and Linux support planned
  • Node.js 18+ and npm
  • Git installed
  • One or more AI coding CLI tools (Claude Code, Opencode, Codex, Gemini CLI, etc.)

Setup Guide

Install AgntSpce and get it running on your machine in minutes.

Install dependencies

npm install

Run in development

npm run dev

This starts the Vite dev server and the Electron app. The server runs on 127.0.0.1:9460.

Build for production

npm run build

Package as Electron app

npm run electron:build

Outputs .dmg (mac), .exe (win), or .AppImage (linux) depending on your platform.

Preview built app

npm run electron:preview

Your First Workspace

A workspace is where all your agent sessions run. It points to a local directory or git repository.

1. Open the Create Workspace dialog

Click the Create Workspace button in the sidebar or use ⌘⇧N.

2. Choose a source

You can either:

  • Local folder — Point to any directory on your machine
  • Git URL — Clone a repository (requires gh auth)
# Or clone from the command line:
git clone https://github.com/user/repo.git ~/AgntSpce/my-project

3. Launch an agent

With your workspace active, click the + button in the terminal area or use ⌘⇧A.

4. Start working

Your agent terminal is ready. You can also open a shell terminal (⌘⇧S), browse files, or open the code editor.

Workspaces

Workspaces are the foundation of AgntSpce. Each workspace has its own sessions, git context, and file explorer.

Creating a workspace

Click Create Workspace in the sidebar, or use the command palette (⌘K). You can create from:

  • Local directory — picks any folder on disk
  • Git URL — clones the repo to ~/AgntSpce/<name>

Switching workspaces

Click a workspace in the sidebar to switch. All your sessions are preserved and restored when you switch back.

Managing workspaces

  • Rename — Edit the name in the sidebar
  • Duplicate — File > Duplicate Workspace
  • Export/Import — File > Save As / Load.
  • Delete — Moves to trash (restorable)

Workspace config

Each workspace stores metadata locally in ~/.agent-workspace/workspaces/<id>.json:

  • Repository path and type
  • Worktree configuration
  • Environment variables
  • Setup and teardown scripts

Launching an agent

Click + or press ⌘⇧A. A picker shows all available agents. Configure mode, flags, model, and verbosity before launch.

Status indicators

  • Idle — Waiting for input
  • Busy — Executing a task
  • Waiting — Prompting for permission
  • Exited — Process terminated

Auto-restart

Claude sessions can auto-restart when they exit. Enable this in Settings.

Shell Terminals

Regular shell sessions alongside your agent terminals. Useful for git commands, build scripts, or any terminal work.

Press ⌘⇧S or click the terminal icon in the activity bar. Shell terminals are visually distinct from agent terminals.

Code Editor

A built-in code editor powered by Monaco Editor (the engine behind VS Code).

Opening files

Click any file in the file explorer sidebar. Files open in new tabs.

Editing

  • Multi-tab editing with dirty indicators
  • Language detection by file extension
  • Syntax highlighting for 20+ languages

Supported languages

TypeScript, JavaScript, Python, Rust, Go, Ruby, Java, C++, CSS, HTML, JSON, Markdown, YAML, SQL, and more.

Git Integration

Stay aware of your repository state without leaving the app.

Branch tracking

Each session shows its current git branch. Branches are polled every 30 seconds.

Git Review panel

  • Commit log — Recent commits with hash, message, author
  • Branches — All branches sorted by date
  • Working tree diff — Unstaged changes
  • Commit diff — Changes in a specific commit
  • File diff — Per-file diff

Worktrees

AgntSpce supports git worktrees for running parallel agent sessions on different branches.

Caveman Mode

Reduce token usage by instructing your AI agent to respond more tersely.

How it works

When enabled, AgntSpce writes a SKILL.md (Opencode) or CLAUDE.md (Claude Code) into your workspace with concise-response instructions.

Lite

~30% fewer tokens

Professional tone, no filler words.

Full

~65% fewer tokens

Fragments, short synonyms, minimal articles.

Ultra

~75% fewer tokens

Telegraphic, abbreviations, max compression.

Output Filter

Reduces noise in terminal output before it reaches you, saving tokens and screen space.

What it filters

  • ANSI escape sequences — Strips color codes
  • Duplicate lines — Deduplicates repeated output
  • Progress bars — Removes progress indicators
  • Empty lines — Collapses blank lines
  • Skip/Keep patterns — Custom regex rules

Debug panel

Shows real-time stats: original vs filtered bytes, reduction percentage, rules applied per event.

Parallel Tasks

Launch multiple agent sessions simultaneously across different worktrees.

Concurrency limits

The orchestrator limits parallel execution to 6 concurrent sessions. Additional requests are queued.

  • CPU usage per session
  • Memory threshold: 1GB
  • Health checks every 15 seconds
  • Max 3 restarts per 60-second window

Configuration

config.json (project root)

{
  "server": {
    "port": 9460,
    "host": "127.0.0.1"
  },
  "sessions": {
    "timeoutMs": 1800000,
    "maxBufferSize": 100000,
    "maxProcessesPerSession": 50
  },
  "logging": {
    "level": "info"
  }
}

~/.agent-workspace/config.json (user config)

Auto-generated on first run. Controls active workspace, recent workspaces, theme preference, and last-workspace memory.

AgntSpce

An open source desktop workspace for running and monitoring AI coding agents inside PTY-backed terminals.

AgntSpce combines workspace management, agent launches, live terminal output, git-aware status tracking, and token-compression metrics in one unified interface. It runs entirely locally — no cloud dependency, no account required, no data ever leaves your machine.

Requirements
  • macOS (Apple Silicon or Intel) — Windows and Linux support planned
  • Node.js 18+ and npm
  • Git installed
  • One or more AI coding CLI tools — Claude Code, Opencode, Codex, Gemini CLI, or any PTY-compatible agent

How It Works

AgntSpce is built around one idea: instead of running your AI coding agents in separate terminals and paying for every wasted token, bring them together in a single local workspace where they can work side by side.

The workflow

  1. Create a workspace pointing at any local folder or git repository.
  2. Launch your agents — Claude Code, Codex, Opencode, Gemini CLI, and more — each in its own isolated PTY-backed terminal.
  3. Watch them work with live streaming output, status detection (idle, busy, waiting, exited), and a dashboard of activity.
  4. Cut token costs — RTK output compression, caveman mode, and semantic search reduce what goes into every agent's context.
  5. Orchestrate in parallel — fan tasks out across isolated git worktrees, compare results, and merge the winner.

What makes it different

  • Local-first — everything runs on your machine, no cloud, no account.
  • Token reduction on every layer — compression, filtering, and search keep costs low without losing context.
  • Zero-config orchestration — AgntSpce auto-detects your installed agents and wires them up.
  • Everything in one place — editor, git review, shell terminals, commander palette, and file explorer ship in the box.

Setup Guide

Install AgntSpce and get it running on your machine in minutes.

Download the app

The easiest way to get started is to grab the latest macOS installer from the Download page and open the .dmg. Windows and Linux builds are coming soon.

Install from source

Prefer to build it yourself? The app is fully open source. Clone the repository and follow the steps below.

Install dependencies

npm install

Run in development

npm run dev

This starts the Vite dev server and the Electron app in development mode. The web server runs on 127.0.0.1:9460 and the Electron window attaches to it automatically.

Build for production

npm run build

Package as Electron app

npm run electron:build

Outputs platform-specific installers: .dmg (macOS), .exe (Windows), or .AppImage (Linux) depending on your build platform.

Preview the built app

npm run electron:preview

Launches the packaged Electron app without rebuilding, useful for quick testing after electron:build.

Your First Workspace

A workspace is the core unit of AgntSpce — it points to a local directory or git repository and contains all your agent sessions, terminal outputs, and workspace metadata.

1. Open the Create Workspace dialog

Click the Create Workspace button in the sidebar, or use the keyboard shortcut ⌘⇧N.

2. Choose a source

You can create a workspace from:

  • Local folder — Browse and select any directory on your machine
  • Git URL — Clone a remote repository (requires gh CLI authentication for private repos)
# Or clone from the command line first:
git clone https://github.com/user/repo.git ~/AgntSpce/my-project

3. Launch an agent

With your workspace active, click the + button in the terminal area or press ⌘⇧A to open the agent picker. Select your preferred AI coding agent, configure the mode and flags, then launch.

4. Start working

Your agent terminal is now ready. You can also open a shell terminal (⌘⇧S), browse files, or open the code editor. The workspace remembers your session layout across restarts.

Workspaces

Workspaces are the foundation of AgntSpce. Each workspace has its own set of agent sessions, shell terminals, git context, file explorer state, and editor tabs.

Creating a workspace

Click Create Workspace in sidebar, or use the command palette (⌘K). You can create from:

  • Local directory — Picks any folder on disk and uses it as the workspace root
  • Git URL — Clones the repository to ~/AgntSpce/<name> and sets up the workspace

Switching workspaces

Click a workspace in the sidebar to switch. All your sessions are preserved and will be restored when you switch back. The workspace switcher shows the current git branch and agent status for each workspace.

Managing workspaces

  • Rename — Right-click and select Rename, or edit the name inline
  • Duplicate — File > Duplicate Workspace creates a copy with a new ID
  • Export/Import — File > Save As exports the workspace config; Load imports it
  • Delete — Moves to trash (soft-delete, restorable from trash panel)

Workspace configuration

Each workspace stores its metadata locally in ~/.agent-workspace/workspaces/<id>.json:

  • Repository path and type (local / git)
  • Worktree configuration
  • Environment variables
  • Setup and teardown scripts
  • UI layout preferences

Launching an agent

Click the + button in the terminal tab bar or press ⌘⇧A. A picker dialog shows all available agents detected on your system. You can configure the launch mode, CLI flags, model selection, reasoning effort, and verbosity level before starting.

Status indicators

  • Idle — Agent is running and waiting for input
  • Busy — Agent is actively executing a task
  • Waiting — Agent is prompting for user permission or input
  • Exited — Process has terminated (may auto-restart)

Auto-restart

Claude Code sessions can be configured to auto-restart when they exit. Enable this behavior in Settings > Agent > Auto-restart. This is useful for long-running development workflows where the agent should resume after completing a task.

Shell Terminals

Regular shell sessions run alongside your agent terminals, giving you full access to your system shell for git commands, build scripts, testing, and any other terminal work.

Press ⌘⇧S or click the terminal icon in the activity bar to open a new shell terminal. Shell terminals are visually distinct from agent terminals with a different color scheme and label.

You can have multiple shell terminals open simultaneously, each in its own tab. The terminal emulator supports standard xterm features including color output, scrollback, and copy/paste.

Code Editor

A built-in code editor powered by Monaco Editor — the same engine that powers VS Code.

Opening files

Click any file in the file explorer sidebar. Files open in new tabs with a dirty indicator (dot) when unsaved changes exist.

Editing features

  • Multi-tab editing with drag-and-drop tab reordering
  • Language detection by file extension
  • Syntax highlighting for 20+ languages
  • Find and replace within files
  • Minimap for quick navigation

Supported languages

TypeScript, JavaScript, Python, Rust, Go, Ruby, Java, C++, C#, CSS, HTML, JSON, Markdown, YAML, SQL, Shell, Dockerfile, TOML, GraphQL, and more. Language support is detected automatically from file extensions.

File Explorer

Browse your workspace files directly in the sidebar, without leaving AgntSpce.

Tree view

The file tree shows your workspace directory, sorted with directories first. Dotfiles are hidden by default. Click to expand and collapse folders.

File operations

  • Create file — Create an empty file in any directory
  • Create folder — Create a new subdirectory
  • Rename — Rename files and folders
  • Delete — Delete files or entire directories

All operations go through the backend and write directly to disk, so the file explorer always reflects the real state of your workspace.

Git Integration

Stay aware of your repository state without leaving the app. AgntSpce provides rich git integration for every workspace.

Branch tracking

Each session displays its current git branch in the session header. Branches are polled every 30 seconds to reflect any changes made externally or by agents.

Git Review panel

  • Commit log — Recent commits with hash, message, author, and relative timestamp
  • Branches — All branches listed and sorted by most recent commit date
  • Working tree diff — Shows unstaged and staged changes in real time
  • Commit diff — View the full diff of any specific commit
  • File diff — Per-file side-by-side diff view

Worktrees

AgntSpce supports git worktrees for running parallel agent sessions on different branches simultaneously. Each worktree gets its own isolated working directory while sharing the same git repository, enabling true parallel development without branch conflicts.

Dashboard

The Dashboard provides at-a-glance visibility into your workspace activity, agent health, and resource usage.

Workspace stats

  • Active agent count and their current statuses
  • Shell terminal sessions
  • Git branch and recent commit information
  • CPU and memory usage per session
  • Uptime and session duration tracking

Token compression metrics

The dashboard displays real-time token optimization statistics including:

  • Original vs filtered output byte counts
  • Token reduction percentage by session
  • Filter rules applied and their individual impact
  • Historical trends and cumulative savings

Caveman Mode

Reduce token usage by instructing your AI agent to respond with shorter, more concise output. Caveman Mode injects style directives directly into the agent's system prompt.

How it works

When enabled, AgntSpce writes a SKILL.md (for Opencode) or CLAUDE.md (for Claude Code) into your workspace root directory with concise-response instructions. The agent reads this file on startup and adjusts its verbosity accordingly.

Lite

~30% fewer

Professional tone, no filler words. Full grammar and sentences preserved.

Full

~65% fewer

Fragments, short synonyms, minimal articles. Technical terms stay exact.

Ultra

~75% fewer

Telegraphic style, abbreviations, max compression. Strips conjunctions and articles.

Output Filter

Reduces noise in terminal output before it reaches your agent's context, saving tokens and screen space.

What it filters

  • ANSI escape sequences — Strips color codes and formatting characters from output
  • Duplicate lines — Deduplicates repeated lines within a configurable window
  • Progress bars — Removes progress indicator lines (e.g., npm/git progress output)
  • Empty lines — Collapses consecutive blank lines
  • Skip/Keep patterns — Custom regex rules for including or excluding specific output patterns

Debug panel

The Output Filter includes a debug panel that shows real-time statistics: original byte count vs filtered byte count, reduction percentage, number of rules applied per event, and a log of filtered content for troubleshooting.

Parallel Tasks

Launch multiple agent sessions simultaneously across different worktrees to maximize productivity.

Concurrency limits

The orchestrator limits parallel execution to 6 concurrent sessions. Additional launch requests are queued and automatically started when a slot opens up.

Resource monitoring

  • CPU usage — Tracked per session with throttling at 80%
  • Memory threshold — Hard limit of 1GB per session
  • Health checks — Performed every 15 seconds on all active sessions
  • Auto-restart policy — Maximum 3 restarts per 60-second rolling window to prevent crash loops

Worktrees

Git worktrees let you check out multiple branches of the same repository simultaneously in separate directories — perfect for running parallel agent sessions without conflicts.

Enabling worktrees

Worktrees are configured per workspace. When enabled, AgntSpce creates worktree directories (e.g., work1, work2) alongside your repo and sets up a git worktree for each.

How agents use them

Agents with worktree support (Claude Code, Opencode, Codex, Cursor Agent, and more) automatically get their own isolated worktree directory when launched in parallel. Each agent operates on its own branch (<name>-dev), so there's no cross-contamination — you compare results and merge the winner.

Managing worktrees

  • Add — Create a new worktree from the base branch (master/main)
  • Remove — Related sessions are closed, then the git worktree is cleaned up

Configuration

config.json (project root)

The project-level configuration file is located at the root of the AgntSpce repository. It controls server settings, session timeouts, and logging.

{
  "server": {
    "port": 9460,
    "host": "127.0.0.1"
  },
  "sessions": {
    "timeoutMs": 1800000,
    "maxBufferSize": 100000,
    "maxProcessesPerSession": 50
  },
  "logging": {
    "level": "info"
  }
}

~/.agent-workspace/config.json (user config)

Auto-generated on first run. Controls user-specific preferences including active workspace, recent workspaces list, theme preference, and last-workspace memory for automatic restoration on startup.

Changelog

Track updates, improvements, and fixes.

v1.2.0 — June 2026

Parallel Agent Execution

Launch multiple agent sessions simultaneously across different worktrees. The orchestrator now supports up to 6 concurrent sessions with health monitoring and auto-restart capabilities.

Output Filter Improvements

Enhanced output filtering with custom regex patterns, real-time debug panel showing compression stats, and improved ANSI escape sequence handling.

New Dashboard

Completely redesigned dashboard with live agent activity feed, token usage metrics, session timeline, and per-agent performance analytics.

  • CPU and memory usage per session
  • Health checks every 15 seconds
  • Max 3 restarts per 60-second window
  • Custom skip/keep regex patterns for output

v1.1.0 — May 2026

Caveman Mode

Reduce token usage by up to 75% with three levels of compression: Lite (~30%), Full (~65%), and Ultra (~75%). Injects concise-response instructions directly into agent context.

Git Integration

Full git awareness with branch tracking, commit log, working tree diffs, and worktree support for parallel agent sessions on different branches.

Code Editor

Built-in code editor powered by Monaco Editor with multi-tab editing, language detection, and syntax highlighting for 20+ languages.

  • Token compression across all layers
  • SKILL.md / CLAUDE.md auto-generation
  • Git Review panel with file-level diffs
  • Editor supports TypeScript, Python, Rust, Go, and more

v1.0.0 — April 2026

Initial Release

The first public release of AgntSpce — a Multi-Agent Workspace IDE focused on cost efficiency, productivity, and power.

  • Workspace management with local directory and git URL support
  • Agent terminals for Claude Code, Opencode, Codex, Gemini CLI
  • Shell terminals alongside agent sessions
  • Session persistence and restore across workspace switches
  • Built-in token optimization tools
  • Real-time agent activity stream
  • Secure local-first architecture
